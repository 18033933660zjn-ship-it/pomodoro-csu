# 🍅 番茄ToDo PRO - 个人时间统筹、课程表协同与全维督学系统

专为**中南大学学子深度定制**，完美融合**理论与专业技能课表、每天3小时雅思强化与AI科研推进、习概与双创导论90分钟、体育专业课三科（运动生物力学、体育科学研究方法、运动竞赛学）各20分钟，以及周末健身房2.5小时高强度拉练**的自动化自律督学系统。

---

## 🌟 本次核心升级亮点

### 1. 📅 高校课表与每日自习日程无缝融合 (`/schedule`)
系统将你在中南大学教务系统的周一至周五课程表深度集成进时间引擎中：
- **周一**：10:00 足球课，19:00 创新创业导论
- **周二**：16:00 专业技能训练(五)
- **周三**：08:00 游泳课，13:00 学术组会，19:00 运动生物力学
- **周四**：08:00 体育科研方法，10:00 羽毛球课，16:00 专业技能训练(五)
- **周五**：10:00 习概课，19:00 运动竞赛学
- **周末**：全天无课，全力攻坚体能与科研

### 2. 📍 严格自习室 / 健身房准时打卡考核机制
- **打卡时限守则**：
  - 系统内置周一至周日全周 **18 个关键自习就位节点**。
  - **必须在预定打卡时间点前（或准点）到达**自习室/健身房点击打卡。
- **迟到自动记入每周总结**：
  - 若超过预定打卡时间点，系统判定为 **❌ 迟到**，精确记录迟到的分钟数，并自动写入周总结改进分析中。
  - 准时到达判定为 **✅ 准时**，播放和弦 Zen Gong 提示音与彩带。
- **实时预警横幅**：应用首页顶部常驻打卡指示，实时显示下一个打卡节点、倒计时及迟到预警。

### 3. 🤖 周日自动化深度复盘与督学总结汇报 (Weekly Automated Coaching)
每周日下午完成既定任务后，系统自动生成周度深度复盘报告：
1. **各项任务完成情况对照**：
   - 任务一（雅思3h+AI科研）：实测 vs 21h 目标
   - 任务二（习概+双创90m）：实测 vs 9h 目标
   - 任务三（专业三科各20m）：实测 vs 5h 目标（细化至运动生物力学、体育科研方法、运动竞赛学）
   - 周末专项（健身房2.5h）：实测 vs 5h 目标
2. **🌟 表扬做得好的地方 (Strengths & Praise)**：表扬守纪出勤、高强度科研和健身突破。
3. **⚠️ 需要改进的地方 (Areas for Improvement)**：客观指出本周每一次自习室迟到明细、某一科目用时缺口及作息松懈点。
4. **🏆 综合评级 (GRADE S / A / B / C)** 与 **🎯 下周作战行动指令**。

### 4. 📈 月度宏观诊断与季度五维平衡战略
- **月报**：汇总全月自习室出勤率、热力贡献网格、薄弱时段诊断与下月突破方向。
- **季报**：五维生活与学业平衡雷达图（学术研读、雅思突破、体能自律、专业技能、正念生活）与 90 天宏观成长跃升。
